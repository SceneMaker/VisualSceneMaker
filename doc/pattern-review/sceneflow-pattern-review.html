How clearly do these interaction patterns describe themselves?

We are building authoring support for Visual SceneMaker, the system used to script how a socially interactive agent behaves and how it interacts with a person. Instead of assembling every flow from scratch, authors should be able to start from ready-made interaction patterns — recurring shapes of interaction such as “ask and wait for an answer” or “remind while waiting”.

Below are 23 candidate patterns, grouped into three levels of complexity. Each one is described in one sentence and illustrated with a concrete example involving an agent and a person.

Please rate, for each pattern, how understandable the description is — not whether you find the pattern useful, and not whether you would need it in your own work. We want to know where the wording, the naming, or the grouping fails to communicate. Comments are optional but especially valuable where you rate something low.
