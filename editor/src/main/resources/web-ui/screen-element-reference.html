Screen properties

Each key in screens defines one named screen. Properties at this level control the top-level flex container.

FieldTypeDefaultDescription
layoutstring"flex-column"flex-column | flex-row — direction of main axis. Use flex-row for side-by-side elements.
alignItemsstring—CSS align-items (cross-axis alignment). In flex-column: horizontal. In flex-row: vertical.
justifyContentstring—CSS justify-content (main-axis alignment). Reversed meaning relative to alignItems (see above).
backgroundstring"transparent"CSS background color or value.
elementsarrayrequiredArray of element definition objects rendered top-to-bottom (or left-to-right in flex-row).
Axis mapping: In flex-column (default), alignItems = horizontal, justifyContent = vertical. In flex-row the axes swap: alignItems = vertical, justifyContent = horizontal.
{
  "screens": {
    "home": {
      "layout": "flex-column",
      "alignItems": "center",
      "justifyContent": "center",
      "background": "#f0f4ff",
      "elements": [ ... ]
    }
  }
}

Common fields

These fields are available on every element type.

FieldDescription
type requiredElement type identifier (see sections below).
styleObject of CSS properties applied directly: {"color":"red","font-size":"1.2rem"}
bindVarreads SceneFlow variable name. The element displays and/or updates this variable. Used by inputs, text, bubble.
sendsVarwrites SceneFlow variable name. Written on user interaction (button click, etc.).
sendsValueValue written to sendsVar on interaction. Default: "true".
bindVar vs content: For sl-text and vsm-bubble, if a static content field is present it takes precedence over bindVar. To make the text dynamically updatable via updateVar, use bindVar only and omit content.

Plugin actions (SceneScript)

These actions are called from SceneFlow/SceneScript via <playaction ref="htmlgui-ws:…">.

ActionParametersDescription
loadScreen screen Switch the active screen. screen must match a key in screens.
updateVar var, value Push a new value to every element whose bindVar or variable field matches var. Works for sl-text, vsm-bubble, vsm-animate, vsm-chart, vsm-feed, vsm-track, etc.
screensToFront — Raise the schema-driven screens iframe to the foreground.
guiToFront — Raise the legacy HTML GUI iframe to the foreground.
vcToFront — Raise the video-conferencing iframe to the foreground.
set element, value Legacy GUI only. Set an element by DOM ID in the currently displayed HTML file.
appendMessage var, role, text Append a message to a vsm-feed variable. role: agent | user | system (default: agent).
clearFeed var Reset a vsm-feed variable to an empty array.
trackEvent var, track, event Append a timestamped {track, event, ts} object to a vsm-track variable (ts stamped server-side). The log is pruned to the last 5 minutes on every call.
clearTrack var Reset a vsm-track variable to an empty array.

Text & Controls

sl-text

Renders a <p> paragraph. Use for labels, descriptions, or any dynamic text display.

FieldRequiredDefaultDescription
contentopt—Static text. Takes precedence over bindVar when present.
bindVaropt—reads SceneFlow variable whose value is displayed. Only used when content is absent.
styleopt—CSS properties object.
Dynamic text: To change the text at runtime with updateVar, omit content and set bindVar instead.
{ "type": "sl-text", "content": "Heart Rate" }

{ "type": "sl-text", "bindVar": "status_label",
  "style": { "font-size": "1.2rem", "color": "#333" } }

sl-button

A Shoelace <sl-button>. Writes a value to a SceneFlow variable on click.

FieldRequiredDefaultDescription
labelopt""Button text.
variantopt"default"default | primary | success | neutral | warning | danger | text
sendsVaropt—writes SceneFlow variable written on click.
sendsValueopt"true"Value written to sendsVar.
styleopt—CSS properties object.
{ "type": "sl-button", "label": "Start", "variant": "primary",
  "sendsVar": "gui_choice", "sendsValue": "start" }

sl-input

Single-line text field. Two-way binding: reads initial value from variable, writes on every keystroke.

FieldRequiredDefaultDescription
labelopt""Field label shown above the input.
bindVaropt—reads writes SceneFlow variable for two-way binding.
styleopt—CSS properties object.
{ "type": "sl-input", "label": "Your name", "bindVar": "user_name" }

sl-textarea

Multi-line text field. Two-way binding like sl-input.

FieldRequiredDefaultDescription
labelopt""Field label.
bindVaropt—reads writes SceneFlow variable.
styleopt—CSS properties object.
{ "type": "sl-textarea", "label": "Notes", "bindVar": "session_notes" }

sl-range

Horizontal slider. Two-way binding; value is a string representation of the numeric position.

FieldRequiredDefaultDescription
labelopt""Field label.
minopt0Minimum value.
maxopt100Maximum value.
stepopt1Step increment.
bindVaropt—reads writes SceneFlow variable (numeric string).
styleopt—CSS properties object.
{ "type": "sl-range", "label": "Intensity", "min": 1, "max": 10,
  "step": 1, "bindVar": "intensity_level" }

sl-checkbox

Checkbox. Reads and writes "true" / "false" strings.

FieldRequiredDefaultDescription
labelopt""Label shown next to the checkbox.
bindVaropt—reads writes SceneFlow variable ("true" / "false").
styleopt—CSS properties object.
{ "type": "sl-checkbox", "label": "I agree", "bindVar": "consent_given" }

sl-select

Dropdown selector. Options can be plain strings or value/label objects.

FieldRequiredDefaultDescription
labelopt""Field label.
optionsopt[]Array of strings or {"value":"…","label":"…"} objects.
bindVaropt—reads writes SceneFlow variable (selected value string).
styleopt—CSS properties object.
{ "type": "sl-select", "label": "Mood", "bindVar": "mood_selection",
  "options": [
    { "value": "happy",   "label": "Happy 😊" },
    { "value": "neutral", "label": "Neutral 😐" },
    { "value": "sad",     "label": "Sad 😢" }
  ] }

Display

sl-badge

Small colored pill / label. Static or variable-driven text.

FieldRequiredDefaultDescription
labelopt—Static text. Overrides bindVar.
variantopt"neutral"primary | success | neutral | warning | danger
bindVaropt—reads SceneFlow variable (used when label is absent).
styleopt—CSS properties object.
{ "type": "sl-badge", "variant": "success", "bindVar": "connection_status" }

sl-card

Shoelace card container with a shadow and border. Can nest any element types as children.

FieldRequiredDefaultDescription
childrenopt[]Array of child element definitions.
styleopt—CSS properties object.
{ "type": "sl-card", "style": { "width": "300px" },
  "children": [
    { "type": "sl-text", "content": "Card title" },
    { "type": "sl-button", "label": "OK", "sendsVar": "gui_choice", "sendsValue": "ok" }
  ] }

sl-divider

Horizontal rule / separator line. No additional fields.

{ "type": "sl-divider" }

Layout

vsm-panel

A flex container that can hold other elements. Use to group elements side-by-side (flex-row) or create a card-like block with a background.

FieldRequiredDefaultDescription
layoutopt"flex-column"flex-column | flex-row (wraps automatically).
alignItemsopt—CSS alignment on the cross-axis.
justifyContentopt—CSS alignment on the main axis.
backgroundopt—CSS background color.
paddingopt—CSS padding (e.g. "1rem").
gapopt"0.5rem"CSS gap between children.
flexGrowoptfalseIf true, expands to fill remaining space (flex: 1).
childrenopt[]Array of child element definitions.
styleopt—CSS properties object.
{ "type": "vsm-panel", "layout": "flex-row", "gap": "1rem", "padding": "1rem",
  "background": "#f5f5f5",
  "children": [
    { "type": "sl-button", "label": "Yes", "variant": "success", "sendsVar": "answer", "sendsValue": "yes" },
    { "type": "sl-button", "label": "No",  "variant": "danger",  "sendsVar": "answer", "sendsValue": "no"  }
  ] }

vsm-filler

Invisible spacer. Use flexGrow: true to push subsequent elements to the opposite edge, or set explicit dimensions for fixed spacing.

FieldRequiredDefaultDescription
flexGrowoptfalseIf true, fills all remaining space (flex: 1). Ignores width/height.
widthopt—Fixed width (only when flexGrow is false).
heightopt—Fixed height (only when flexGrow is false).
{ "type": "vsm-filler", "height": "2rem" }

{ "type": "vsm-filler", "flexGrow": true }   // pushes next element to bottom/right

Dynamic

vsm-bubble

Chat-style speech bubble. Position (left/right) is controlled by align-self in style. Tail direction is set separately.

FieldRequiredDefaultDescription
contentopt—Static text. Used when bindVar is absent or empty.
bindVaropt—reads SceneFlow variable. Overrides content when the variable has a value.
backgroundopt"#e8f4fd"Bubble background color (CSS).
tailopt"bottom""bottom" | "top" | "none" — tail direction.
speakeropt—Speaker name shown above the bubble (e.g. "ARIA").
styleopt—CSS properties. Use "align-self": "flex-end" for right-aligned (user) bubble; "flex-start" or omit for left-aligned (agent).
Alignment: In a flex-column screen, align-self controls horizontal position. flex-start = left (agent), flex-end = right (user), center = centered (no tail).
{ "type": "vsm-bubble", "bindVar": "agent_speech",
  "background": "#e8f4fd", "tail": "bottom", "speaker": "ARIA",
  "style": { "align-self": "flex-start" } }

{ "type": "vsm-bubble", "bindVar": "user_speech",
  "background": "#eafbe8", "tail": "bottom",
  "style": { "align-self": "flex-end" } }

vsm-chart

Chart.js chart. The bound variable must hold a JSON string in Chart.js dataset format.

FieldRequiredDefaultDescription
chartTypeopt"bar"bar | line | pie | doughnut
dataVarreq—reads SceneFlow variable holding Chart.js dataset JSON string.
labelopt""Default dataset label.
coloropt—Default bar/line color (CSS).
widthopt"100%"CSS width.
heightopt"300px"CSS height.
styleopt—CSS properties object.
{ "type": "vsm-chart", "chartType": "line", "dataVar": "sensor_data",
  "color": "#5b8edc", "height": "250px" }

The variable value should be a Chart.js-compatible JSON string, e.g.:

{ "labels": ["Mon","Tue","Wed"], "datasets": [{ "label": "BPM", "data": [72,68,75] }] }

vsm-feed

Scrollable conversation feed displaying a JSON array of role-aware message bubbles. New messages are appended at runtime via appendMessage.

FieldRequiredDefaultDescription
dataVarreq—reads SceneFlow String variable holding a JSON array of message objects.
agentColoropt"#e8f4fd"Background color for agent bubbles.
userColoropt"#eafbe8"Background color for user bubbles.
systemColoropt"#f5f5f5"Background color for system messages.
agentLabelopt"Agent"Name shown above agent bubbles.
userLabelopt"You"Name shown above user bubbles.
showTimestampsoptfalseShow timestamp field from message objects.
heightopt"400px"Scroll container height.
widthopt—CSS width.

Message object format (array stored in the variable):

FieldDescription
role"agent" (left, agentColor) | "user" (right, userColor) | "system" (centered, italic, no tail)
textMessage text.
speakerOptional override name shown above the bubble.
timestampOptional timestamp string (shown when showTimestamps: true).
{ "type": "vsm-feed", "dataVar": "conversation_log",
  "height": "500px", "agentLabel": "ARIA", "userLabel": "Participant",
  "agentColor": "#dce8ff", "userColor": "#dcf5dc" }

Append from SceneScript:

<playaction ref="htmlgui-ws:appendMessage" var="conversation_log"
            role="agent" text="$agent_utterance"/>

vsm-animate

Pre-built CSS/SVG animation whose parameters (rate, color, amplitude, opacity) are driven live by SceneFlow variables.

FieldRequiredDefaultDescription
animationreq"heartbeat"heartbeat | breathe | wave | pulse | spinner
rateVaropt—reads Numeric variable controlling speed. Semantics are animation-specific: BPM for heartbeat, breaths/min for breathe, Hz for wave.
colorVaropt—reads CSS color string variable.
amplitudeVaropt—reads 0–100 scale variable controlling amplitude.
opacityVaropt—reads 0–100 variable mapped to CSS opacity 0–1.
coloropt—Default color when colorVar is not set or empty.
widthopt—CSS width (e.g. "120px").
heightopt—CSS height.
styleopt—CSS properties object.
animationrateVar semanticsNotes
heartbeatBPM → animation-durationSVG heart that pulses. Typical range 40–180.
breathebreaths/minExpanding/contracting circle. Typical range 8–25.
waveHzHorizontal sine wave. Typical range 0.5–4.
pulserate (generic)Radial ripple — use for microphone active state.
spinnerRPMRotating arc.
{ "type": "vsm-animate", "animation": "heartbeat",
  "rateVar": "hf_bpm", "colorVar": "heart_color",
  "color": "#e26d5a", "width": "120px", "height": "120px" }

Update from SceneScript at runtime:

<playaction ref="htmlgui-ws:updateVar" var="hf_bpm"   value="$hf_bpm"/>
<playaction ref="htmlgui-ws:updateVar" var="heart_color" value="#cc0000"/>

vsm-track

Real-time multi-lane event timeline. Events are appended at runtime via trackEvent; within a lane, start-<name>/stop-<name> events pair into a duration bar, and any other event name renders as an instantaneous tick. The viewport scrolls live and can be paused to scrub back through the retained history.

FieldRequiredDefaultDescription
dataVarreq—reads SceneFlow String variable holding a JSON array of {track, event, ts} objects.
tracksoptauto-discoveredArray of {id, label, color} defining lane order/labels/colors. When omitted, lanes are discovered from the data in first-seen order with a default color cycle.
windowSecondsopt60Width of the visible, live-scrolling viewport, in seconds.
bufferSecondsopt300How far back the pause scrubber can reach. Actual retention is enforced server-side by trackEvent at a fixed 5 minutes, independent of this field.
widthopt—CSS width.
heightopt"220px"CSS height.

Event object format (array stored in the variable):

FieldDescription
trackLane id this event belongs to, e.g. "user" or "sia".
eventEvent name. "start-<name>" / "stop-<name>" pairs on the same track draw a duration bar labeled <name>; a start- with no matching stop- yet is drawn open-ended out to the current time. Any other name draws an instantaneous tick.
tsEpoch milliseconds, stamped server-side by trackEvent when the action executes (not supplied by the caller).
Pause/scrub: a play/pause control in the element's corner freezes the live viewport and reveals a scrubber spanning the retained buffer; resuming snaps back to the live edge. This is purely a client-side viewing concern — no SceneFlow variable is involved, so scrubbing never affects the underlying log.
{ "type": "vsm-track", "dataVar": "activity_track",
  "tracks": [
    { "id": "user", "label": "User", "color": "#4a90d9" },
    { "id": "sia",  "label": "SIA",  "color": "#d9704a" }
  ],
  "windowSeconds": 60, "bufferSeconds": 300, "height": "220px" }

Record events from SceneScript:

<playaction ref="htmlgui-ws:trackEvent" var="activity_track" track="sia"  event="start-speak"/>
<playaction ref="htmlgui-ws:trackEvent" var="activity_track" track="sia"  event="stop-speak"/>
<playaction ref="htmlgui-ws:trackEvent" var="activity_track" track="user" event="start-smile"/>
<playaction ref="htmlgui-ws:trackEvent" var="activity_track" track="user" event="stop-smile"/>
