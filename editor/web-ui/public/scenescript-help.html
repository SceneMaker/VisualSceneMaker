SceneScript Guide

How to write and edit dialogue scripts in Visual SceneMaker

Overview

A SceneScript is the text file behind every scene in a project — the dialogue itself, grouped into scenes and turns, plus optional sections and notes for structuring the document, and inline commands for triggering character behavior (backgrounds, emotions, pauses, and more) at a precise point in the dialogue.

Keep this page current. Whenever script authoring gains a new construct or editing feature, add a section here describing it.

Scenes & turns

A scene starts with the scene keyword, a two-letter language code, and a name:

scene en warmup
Bob: Hello there, how are you doing today?
Alice: I'm doing well, thanks for asking!

Each turn is one line starting with Speaker: followed by one or more sentences. A new scene always starts with the scene keyword again.

Inline commands

Commands are written in square brackets inside a turn's dialogue text, and trigger an action at exactly that point in the utterance: 

Bob: Let's begin. [background image='park.jpg'] Look around you.
Bob: I'm so happy right now! [emotion type='joy' intensity='0.8']

A command's own actor defaults to the turn's speaker. To target a different character than the one speaking, prefix the command with that character's name: 

Bob: Watch this. [Alice: emotion type='surprise']

Common commands include:

CommandPurpose
backgroundChange the scene's background image or color
emotionPlay an emotional expression on a character
pauseHold the turn for a moment before continuing

Blocking vs. fire-and-forget

In compact view, every command chip shows a small icon indicating whether it blocks the turn until it finishes (a clock icon — this is always the case for pause, and for any command with the feature blocking='true'), or fires without waiting (a rocket icon — the default for everything else).

Sections

Sections are markdown-style headings used to structure a long script into readable parts — they are not dialogue and are never spoken. Use one, two, or three # characters for heading level: 

# Introduction

## Warm-up

### Task 1

Sections (and notes, below) only work between scenes — as their own line, separated from surrounding scene content by a blank line. There is no inline version.

Notes

Notes are short explanatory remarks for whoever is authoring or reviewing the script — reminders, instructions, or context — written in plain English, not code-style comments: 

Note: remember to smile before this line

scene en task
Bob: Let's begin.

Both sections and notes support **bold** and *italic* / _italic_ text.

Compact / plain view

The toolbar button next to the script editor toggles how the script is displayed:

  • Code-view icon — showing the raw text exactly as typed, including [...] brackets, # headings and Note: prefixes. This is also the only mode you can type directly into a heading or note.
  • Text icon — a rendered, easier-to-read view: inline commands become compact chips, and headings/notes are styled.

Editing inline commands

In compact view, an inline command becomes a chip you can interact with directly:

  • Click a chip to select it, then press Backspace/Delete to remove it.
  • Drag a chip to move it elsewhere within the same turn.
  • Double-click a chip to open its edit dialog and change its parameters.
  • Double-click plain dialogue text to insert a new command at that point.

SIA preview panel

The Preview panel lets you load a character and test Background/Emotion commands live before writing them into the script — use each column's "Insert at cursor" action to drop the exact command text at your current position in the script editor.
