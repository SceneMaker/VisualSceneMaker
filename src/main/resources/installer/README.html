VSM Web

Visual Dialogue Authoring & Runtime Platform — DFKI GmbH

Installation

1
Drag VSM Web.app to the Applications folder on the left.
2
Open Finder → Applications and locate VSM Web.
3
Right-click (or Control-click) the app and choose Open.
macOS will show a security warning — click Open to confirm.
You only need to do this once. After that, double-clicking works normally.
If you see "cannot be opened" without an Open option after double-clicking:
  1. Click here to open Security & Privacy Settings ↗
  2. Scroll to the bottom — you will see "VSM Web was blocked from use"
  3. Click Open Anyway, then confirm with Open
Why the warning? VSM Web is free research software and is not signed with an Apple Developer certificate. The right-click → Open bypass is the standard workaround for academic and open-source software. It does not change any system-wide security settings.

First launch

4
VSM Web starts a local web server and opens your browser automatically at http://localhost:8090. If the browser does not open, navigate there manually.
5
To quit, close the browser tab and use the VSM Web menu → Quit, or press ⌘Q.

VSM Web is developed at the German Research Center for Artificial Intelligence (DFKI), Saarbrücken. Source code and documentation: github.com/DFKI-NLP/VisualSceneMaker
