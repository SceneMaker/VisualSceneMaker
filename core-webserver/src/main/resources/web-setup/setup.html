📄 One-time setup. To see the character, this computer needs to trust the session's security certificate. It takes about a minute.
1 · Download certificate
macOS Windows Linux
  1. Double-click the downloaded vsm-ca.crt. This opens Keychain Access and imports the certificate — but it is not trusted yet (this step alone is not enough).
  2. In Keychain Access, type mkcert in the search box (top-right) and double-click the “mkcert …” entry to open its info window.
  3. Click the triangle next to ▸ Trust to expand it, then set “When using this certificate:” → “Always Trust.”
  4. Close the info window (red dot or ⌘W). macOS will ask for your login password — enter it. ⚠️ If you don't get a password prompt, the trust was not saved; reopen the entry and set it again.
  5. To confirm it stuck: reopen the entry — it should say “This certificate is marked as trusted.”
  6. Fully quit and reopen your browser (⌘Q — not just the tab), then continue below.
  1. Double-click the downloaded vsm-ca.crt → Install Certificate.
  2. Choose Current User → Place all certificates in the following store → Trusted Root Certification Authorities → Finish → confirm.
  3. Fully close and reopen your browser.
  1. Import vsm-ca.crt into your system trust store (e.g. copy to /usr/local/share/ca-certificates/ and run sudo update-ca-certificates).
  2. Firefox uses its own store: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import (trust for websites).
  3. Fully close and reopen your browser.

Why? The character runs in your browser and needs a secure (HTTPS) connection to load. A one-time trusted certificate makes that work with no warnings — for this session and future ones.

Skip (character won't work)
Still not trusted. The most common reasons:
  • The trust setting wasn't saved — on macOS you must close the certificate window and enter your password. Reopen the “mkcert …” entry to check it says “marked as trusted.”
  • You only imported the file (double-click) but didn't set Always Trust.
  • The browser wasn't fully quit and reopened (a tab reload isn't enough).
Fix and press Continue again.
